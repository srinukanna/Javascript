### Introduction
* it is a javascript runtime and it is built on chrome's v8 js engine.

* Simply,it is a cross platform,open-source js runtime environment that can run on windows,linux,Unix,MacOs and more.

* It runs on the v8 Js engineand executes js code outside a web browser.

* It is maintained by openJs foundation community.

### Main Functions of Nodejs

```
It makes developers use js to write command line tools and for server-side scripting.
```

The ability to run js code on the server is often used to generate dynamic web content.

### Advantages of Nodejs

* It uses Event driven architecture.

* it is a capable of asynchronous I/O or Non blocking I/O.
